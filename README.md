# Метро Київ

Легкий встановлюваний PWA для київського метро: вибір станції, напрямку та
типу дня, посекундний розрахунковий таймер, найближчі відправлення, схема
трьох ліній, обрані станції й темна тема.

## Дані та точність

Застосунок використовує відкриті дані Києва про станції, напрямки, режим
роботи й погодинні інтервали руху. Таймер розраховує орієнтовний час до
відправлення і оновлюється щосекунди. Це не live-дані диспетчерської служби:
під час тривог чи оперативних змін фактичний рух може відрізнятися.

## Локальний запуск

Потрібен Node.js 22 або новіший.

```bash
npm install
npm run dev
```

## Публікація

Cloudflare Pages збирає застосунок з гілки `main` командою `npm run build` і
публікує каталог `dist` на [metrokyiv.pp.ua](https://metrokyiv.pp.ua/).
